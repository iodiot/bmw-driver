# Перенос BMW на Mac

Архив `bmw-driver-macos.zip` содержит текущую версию v26, предыдущие модели, исходники, референсы, отчёты, историю Git и Three.js для запуска без установки npm-пакетов. Приватные настройки Windows, локальные нейросети и исполняемые файлы Windows исключены. Не распаковывайте архив поверх существующего проекта.

1. Скачайте архив на Mac и распакуйте его в обычную папку, например `Documents/Projects`.
2. В Codex на Mac откройте распакованную папку **bmw-driver** как локальный проект и начните работу в ней. Существующий чат подключён к Windows; скачивание архива само по себе не меняет компьютер выполнения этого чата.
3. Откройте `Start BMW.command`. Нужен Python 3. Если macOS не разрешает запуск двойным щелчком, откройте терминал в папке проекта и выполните `bash "Start BMW.command"`. Скрипт поднимает сервер на свободном локальном порту и открывает машину в браузере. Закрытие сервера останавливает просмотр.
4. Для изменения процедурной геометрии создайте Python-окружение: `python3 -m venv .venv`, затем `.venv/bin/python -m pip install -r requirements.txt`. Запускайте моделирующие скрипты из корня проекта. Готовые GLB уже входят в архив; пересборка для просмотра не требуется.

Правила перенесены в `AGENTS.md`: локальные нейросети отключены, оптимизация модели пока приостановлена, отправка новых изменений в GitHub без отдельного запроса запрещена. Облачная генерация кода остаётся в Codex; файловые операции, сборка и просмотр после открытия проекта на Mac должны выполняться на Mac.

Исходный Git remote сохранён: `https://github.com/iodiot/bmw-driver.git`. Последние локальные изменения в удалённый репозиторий не отправлялись. В архиве новая независимая папка `.git`, без ссылок на рабочие копии Windows.

После проверки запуска на Mac можно остановить сервер и Cloudflare Tunnel на Windows. Старый адрес trycloudflare указывает на Windows и не переезжает вместе с архивом. Доступ с других устройств при необходимости настраивается отдельно уже для Mac.

Фактически проверены: целостность архива, включение GLB v26 и истории Git. Запуск на macOS не проверен: из текущего чата нет доступа к этому компьютеру.
